## Printing implications

Read the final statistics and `PRINTING_REVIEW.md`. Canonical generation rejects paths below 2.8 mm, including short imported paths that the inherited clipper's fully-visible fast path would otherwise retain. This is a Summer wrapper, not a change to accepted catalog code. Exact panel clipping can still create shorter boundary fragments; they are preserved with original-arc parameters and flagged. Decide their physical treatment later instead of silently moving a seam or adding strokes.

The v10 catalog's design width and clearance assumptions are preserved as artistic grammar metadata. They do not install a measured Baegunmo footprint or map artistic expression to physical Z. Nominal planning envelopes support reciprocal 2.5D exclusions; hidden branches, wet expansion, drying, terrain overhangs and brush dynamics are not certified.

## Reproduction and invariants

Run the README commands with verified existing TIFFs. Use an independent directory and no private pickle cache to regenerate all geometry. Generated timing diagnostics may vary between solver runs; canonical vectors, source lineages and panel geometry should match byte for byte on the recorded environment. `verify.py` checks all inherited tracked bytes against the pinned artistic parent, exact original-arc geometry, aligned width/opacity intent, interval ledgers and lossless panel splitting.

New tests include corruption rejection and repeated seam crossings, rather than checking only output counts. Accepted Tree v10, Rock v05, A solver and Mid/Far policy tests are also exercised. No G-code, controller setting, hardware profile, physical pigment allocation or existing PR is modified.

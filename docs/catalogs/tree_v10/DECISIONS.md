# Tree catalog decisions — v02 to v10

This is a short design history, not an invitation to reopen the visual grammar.
All full historical experiments remain in the artist's local archive/worktree.

| Pass | Decision and reason |
| --- | --- |
| v02 | Establish P hero/exposed, B broadleaf/group default and U subordinate mass. Compare fans, layered ribbons and hybrids; built trunks and grouped canopies replace one-line icons. |
| v03 | Unequal growth episodes, joints, support points and branch-led asymmetry improve the body. Open/released foliage loses some directional pattern and coherent canopy mass. |
| v04 | Controlled trunk/canopy hybrid comparisons fail to recover the desired balance. More released internal variation is rejected as the production canopy direction; do not retain a second hybrid engine. |
| v05 | Return to V02 directional fans. Keep grouped readability; soften repeated fixed touch counts with bounded counts and angles. Layered ribbons and ribbon/fan hybrids are not separate production families. |
| v06 | Add pad ownership, dense core / lighter edge / partial omission, whole-unit rotation and articulated terminal behavior. Preserve visible procedure rather than random scatter or literal traditional brush imitation. |
| v07 | Reduce both touches per unit and unit count for plotting scale. Introduce safe contour sections, physical paired-to-single collapse and minimum-length/gap assumptions. These are not measured brush calibration. |
| v08 | Carry the lighter physical logic across P/B/U and retain role distinctions. Larger U remains conditional; parameters and local clusters are reviewed together. |
| v09 | Separate posture, lower-stem ratio, vigor and damage. Add bounded scale budgets and actual descending secondaries for experimental W. Higher budgets do not guarantee more units because candidates and spacing limit placement. |
| v10 | Refine large trees mainly through selected extra touches within existing units and subtle correlated lengths. Keep unit-count gain separate and normally at 1. Accept the grammar provisionally; keep W experimental and U light/small. |
| Final handoff | v10 selective clipping is a useful vector foundation but leaves overly strong inner-canopy terrain. Artistic region-dependent occlusion, roots/supporting ground and physical execution remain unresolved. |

The goal remains a recognizable Datascape procedural stroke system informed by
pictorial organization, not a literal imitation of traditional painting.
No fifth tree engine, botanical expansion, further naturalism pass or scene-wide
spring refinement is part of this consolidation.

The scene-side PR #17 compression trials are not adopted or included. The
selected PR #16 spring baseline remains fixed. Strong foreground ground masses,
root attachment and selective ground visibility are not assumed to follow from
C strokes, tree catalog geometry or wash alone.

## Composition and contour endings

B is a connected, parameterized multi-mass composition with unequal dominance,
local orientation/spacing differences, partial burial and actual near/far overlap.
A is one coherent exposed mass with internal planes, available when the composition
calls for it. They are composition policies on the shared engine, not new species
or a fixed silhouette catalog. No procedural mountain system is introduced.

Some contour endings remain slightly mechanical. The current v05 termination is
accepted for provisional use. A future matched visual evaluation may selectively
add terminal irregularity, short discontinuities or limited dissolution at
weathered joints, Soil contacts and mist transitions. Do not modify all endings,
add independent random noise or reopen the generator in the first integration pass.

## Ink patches, color supports and C

The accepted design direction is a related local ground context with two separately
controlled responsibilities:

- Ink patches: usually smaller, structurally concentrated rock/root/ground support,
  represented by actual open ink-vector paths.
- Color supports: potentially broader, partly offset and able to relate several ink
  concentrations; neither uniform fills nor automatic host-size proportions.

v05 already keeps `GroundStudy.pigment_support`, `PatchControls.pigment_enabled` and
`pigment_fraction` separate from ink, patch ownership and whitespace. That current
support is derived within existing patch ownership; it does **not** yet provide
independently larger/offset color regions. Required future extension: stable shared
context and member IDs, independently authored color support specs/extent/offset,
independent internal pigment density intent, compatible ownership/corridor/depth
checks and provenance linking color support to its related ink patches. Keep current
v05 support bytes unchanged. No new engine or automatic fill is implemented here.

The canonical scene C layer is primarily color-oriented, subject to later depth and
production assignment. Exclude it from structural black-ink previews while retaining
source IDs, geometry and all interaction evidence. C is a directional vector source,
not a Soil ink family or the same thing as a wash polygon. Overlap never justifies
merging source identities. Digital diagnostic colors do not define the final palette,
opacity, brush pressure, pigment concentration or real wash behavior.

## Evidence boundaries

Selective structural line omission, inherited fracture clipping, body visibility,
material footprint clearance and pictorial corridor protection remain separate reasons.
Synthetic depth rank is not geographic source depth. Retain all OCC-01–08 as open
integration/physical gates; no synthetic example closes reciprocal F2 masking.

The optional local C0 protected-support proposal fixes one synthetic crossing only.
An earlier arc-substring replacement exposed endpoint precision loss (about .011 mm²
residual assumed-footprint overlap). The final isolated proposal uses the existing
polygon-region contract on original C paths. The shared consumer is unchanged; test
source-arc endpoint precision before real scene use. Canonical C is not shortened.

Korean painting references informed major/subordinate mass relationships, selective
local density, vegetation and meaningful blank intervals, without copying historical
brush forms or making geological claims. User-provided images remain in the local
review archive and are not republished as catalog assets.

이 Work는 출력과 초지가 끝난 입체 한지 회화의 채색용 G-code를 만드는 작업이다. 아래 지침을 이번 기준으로 사용해줘. 현재 논의만 반복하지 말고, 기존 백엔드를 읽고 한지용 연결 코드·프로필·경로 미리보기·검토용 G-code를 구현해줘. 장비 전송과 실제 구동은 포함하지 않는다.

## 1. 이번 잠정 결정과 작업 범위

- 채색은 사용자가 선택한 C안, 전체 6,200점. 원본 위치·색·선택 밀도를 보존한다.
- 첫 실제 벤치마크는 실물 4번 패널이며 C안 890점이다.

- **잠정 기본값: 실제 국소 표면의 최초 접촉 Z에서 3.0 mm 추가 눌림. 목표 깊이 도달 후 1.00초 정지.** 모든 점에 일정하게 적용한다.
- **실제 작품 점 접촉 20회마다 같은 색을 보충한다.** 첫 공급 이후 20점을 찍고, 21번째를 찍기 전에 보충한다.
- 같은 색을 하나의 묶음으로 끝까지 진행한다. 다른 색을 시작하기 전에 PR32의 색 교체 세척·퍼지·새 색 공급을 수행한다.
- 각 색 안에서는 하단에서 상단으로 진행한다. 첫 유효 행의 오른쪽에서 시작하는 것을 기본으로 하며 왼쪽 시작도 설정할 수 있다.
- 작품 위 비접촉 이동은 검토된 고정 호버 평면을 우선 사용하고, 각 점의 접촉 높이는 입체 표면을 따른다.

이 문서가 이전 3mm/0.5초, 4mm/1초 비교 지침을 대체한다. **이번에 우선 구현·생성할 기본 조합은 3mm/1초/20점 하나**다. 과거 비교 조합을 자동 생성하거나 기본 파일에 섞지 않는다. 30점 보충으로 늘리지 않는다.

1초 체류에서 물감이 실제로 20점까지 유지된다는 실측은 아직 없다. 20점은 잠정 시험 기준이다. 카운터를 설정으로 분리해 나중에 10/15점 등으로 줄일 수 있게 하되, 현재 기본값을 임의 변경하거나 미측정 물감 소비 모델로 자동 보정하지 않는다. 깊이·정지 시간을 점 번호나 색에 따라 자동 조절하지 않는다.

정규화된 예술 필압 0–1을 사용하지 않는다. 여기서 필압은 처음 닿은 실제 표면을 기준으로 한 **추가 눌림 mm**다. Z축 방향 눌림이며, 곡면 법선 방향 3mm 이송이나 힘 센서 피드백 제어를 요구하는 것이 아니다. 사용자 표면 편차 추정 1–2mm는 높이 보정의 불확실성이며 3mm 설정을 바꾸라는 지시가 아니다.

이번 핵심 개발 범위는 ① 명시적인 점 접촉 동작 ② 입체 높이와 기계 좌표 연결 ③ 접촉 횟수 기반 보충 ④ 색 순서와 아래→위 실행 계획이다. 공급·세척의 세부 동작은 최신 검증 백엔드를 재사용한다.

## 4. 패널 번호와 좌표

작품을 정면에서 본 실물 번호는 다음과 같다.

| 위치 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 위 | 실물 1 / 원본 P07 | 실물 2 / P08 | 실물 3 / P09 |
| 가운데 | 실물 4 / P04 | 실물 5 / P05 | 실물 6 / P06 |

- 글로벌 원점: 전체 작품 좌하단. X는 오른쪽, Y는 위쪽.
- 개별 패널 원점: 해당 200 mm 패널의 명목 외곽 좌하단.
- 전체 조립 작업: 글로벌 XY 사용.
- 개별 작업: 로컬 XY 사용. 기계의 실제 장착 위치는 별도 변환으로 적용.
- 설계 Z=0: 출력 베드에 닿았던 골조 뒷면의 설계 평면.
- 설계 최고 높이: 20 mm. 기본 높이 2 mm가 이미 포함되어 있다.

패널별 최저 Z를 빼거나 Base를 다시 더하지 않는다. 패널 로컬 XY에서 높이를 조회할 때는 원래 패널의 글로벌 위치로 돌려 높이 함수를 평가한다. 기계에 놓는 패널을 임의 회전·미러링하지 않는다.

실물 4번은 글로벌 X=0…200, Y=200…400이다. C의 4번 채색점 Z 범위는 약 3.995497…16.921111 mm다. 이는 **점들의 Z 범위이며 이동 영역 전체 표면의 최고 높이를 증명하는 값은 아니다.**

## 5. 색 순서 — S3a의 색별 1회 진행 원리를 유지

PR32의 Spring `SLOT_ORDER`는 다음 12색이다.

`C1 → D1 → A2 → D2 → C2 → A4 → A3 → A5 → C3 → D4 → C4 → D5`

이번 한지의 8색은 `A3, A4, B1, B2, C2, C4, C5, D4`다. 기존 12색 목록만 필터하면 B1·B2·C5가 누락되므로 그렇게 처리하지 않는다. 세 색의 스테이션은 기존 프로필에 존재한다.

**한지용 잠정 확장 순서:**

`C2 → A4 → A3 → D4 → C4 → B1 → C5 → B2`

이 순서는 공통 색의 S3a 상대 순서 `C2 → A4 → A3 → D4 → C4`를 보존하고, 기존 목록에 없던 세 색을 화면 HEX의 명도 순서에 맞춰 삽입한 한지용 확장안이다. 기존 S3a에 이미 정의된 공식 8색 순서라고 표현하지 않는다. 실제 물감 농도/명도를 측정한 순서도 아니다.

이번 벤치마크에는 이 확장 순서를 사용하고 프로필·미리보기·실행 로그에 명시해줘. 작업에 없는 색만 제외하며, 사용된 색은 누락 없이 각각 한 번의 묶음으로 방문한다.

실물 4번에는 6색만 있다. 적용 순서는:

`C2 → A3 → D4 → C4 → B1 → C5`

각 색을 모두 찍은 뒤 다음 색으로 넘어간다. 같은 색 보충에는 세척을 넣지 않고, 색 변경 전에는 PR32의 세척·퍼지·필요한 재습윤·새 색 공급 절차를 사용한다. 색을 알파벳순으로 재정렬하거나 HEX를 임의 혼색하지 않는다.

## 6. 아래에서 위로 진행하는 점 순서

시각적으로 패널/작품 하단에서 시작해 상단으로 올라가도록 한다.

1. 먼저 위의 색 순서로 묶는다.
2. 각 색 안에서 Y가 낮은 행부터 높은 행으로 진행한다.
3. 첫 유효 행은 오른쪽에서 왼쪽으로 시작하는 것을 기본으로 한다.
4. 이후 행 안에서는 X 방향을 번갈아 바꾸는 왕복 정렬을 사용해 이동을 줄인다. 찍는 점들의 행은 Y 오름차순을 유지한다.
5. 왼쪽 시작은 설정으로 바꿀 수 있게 한다. 전체 작업 중 임의로 시작 모드를 바꾸지 않는다.

개별 패널은 로컬 Y 기준, 전체 조립은 글로벌 Y 기준이다. 전체를 실물 번호 1→9 순서로 그리면 상단부터 시작하므로 그렇게 정렬하지 않는다. 색이 바뀌면 그 색의 가장 낮은 유효 행에서 다시 시작한다.

정확히 모서리 (0,0) 또는 (200,0)에 점이 없는 경우 실제 최하단 후보에서 시작한다. 모서리에 가짜 점을 추가하지 않는다. 행 묶음은 CSV의 정밀도와 실제 격자 위치를 기준으로 결정하고, 정렬을 위해 좌표를 스냅하거나 이동시키지 않는다.

물감 보충이나 세척을 위해 Y가 낮아지는 이동은 허용한다. 아래→위 원칙은 **작품에 찍는 순서**에 관한 것이다. 리필 후 다음 미완료 점부터 계속하고, 이미 찍은 점을 다시 찍지 않는다. 원본 점 ID와 실행 순서의 대응표를 남긴다.

## 7. 명시적인 점 접촉 동작

한 점을 그릴 때 XY는 고정하고 다음 순서를 실행한다.

1. 검토된 고정 호버 높이에서 해당 XY로 이동.
2. 위치별 최초 접촉 Z보다 위의 비접촉 접근 위치까지 하강.
3. 제어된 속도로 최초 접촉 위치를 지나 추가 3.0mm 눌림까지 하강.
4. **목표 깊이에 도달하고 움직임이 완료된 뒤 1.00초 정지.**
5. XY 이동 없이 제어된 속도로 눌림을 풀고 표면 접촉에서 이탈.
6. 고정 호버 평면까지 상승한 뒤 다음 점으로 이동.

```text
compression_depth_mm = 3.0
dwell_at_depth_s = 1.0
Z_press_i = Z_first_touch_i - compression_depth_mm
```

1초는 하강과 상승을 포함한 총 접촉 시간이 아니라 **목표 깊이에서의 정지 시간**이다. 하강 시간을 체류시간에서 빼지 않는다. 실제 종이와의 총 접촉 시간은 제어된 눌림·체류·해제의 합으로 더 길어진다.

PR32 연결 초기값은 비접촉 Z F7000, 접촉/눌림/제어된 이탈 F2000이다. F2000=약33.33mm/s이므로 3mm 등속 이동만 계산하면0.09초다. 실제 시간은 가감속·접근 거리·축 설정·붓 응답을 포함해 평가한다. 3mm 하강이 반드시0.09초에 끝난다는 실측 주장이 아니다. 별도 하강 속도 최적화나 작은 붓 전환을 이번 요구에 끼워 넣지 않는다.

기존 직렬화기와 컨트롤러의 G4 시간 단위, 앞선 이동 완료와 dwell의 순서를 코드에서 확인한다. 직렬화한 G-code를 다시 읽어 **1.00초** 정지가 보존되었는지 검증한다. 초/밀리초를 임의 가정하지 않는다.

점에는 독립적인 접촉 이벤트/실행 프리미티브를 사용한다. 0길이 획을 기존 검증에 억지로 통과시키거나 작은 XY 선분을 만들어 점을 흉내 내지 않는다. 체류 중 XY 흔들기·원 그리기·추가 압입·반복 타격은 하지 않는다. Spring의 예술 필압 곡선을 통과시키지 않는다.

스테이션별 접촉 속도와 담금 깊이는 기존 독립 설정을 유지한다. 종이용3mm와1초를 물감통·세척·스펀지에 일괄 적용하지 않는다.

## 8. 설계 Z, 실제 표면, 기계 Z의 변환

CSV의 Z를 곧바로 G54 Z 명령으로 쓰지 않는다. 현재 PR32의 평면 종이 최초 접촉은 G54 Z=10이며, 기존 평면 호버 Z=20은 그 위 10 mm이다. 입체 패널을 올려놓으면 표면의 첫 접촉 Z도 올라간다.

단순한 평행 장착이라면 다음 형태로 관리할 수 있다.

```text
Z_first_touch_i = z_design_i + hanji_surface_offset_z_mm + local_surface_correction_i
Z_press_i = Z_first_touch_i - 3.0
```

`hanji_surface_offset_z_mm`는 실제 장착 기준과 붓의 첫 접촉 측정에서 정한다. 기존 평면의 접촉 Z=10을 모든 경우에 그대로 더하는 값으로 취급하지 않는다. 기준 종이의 높이, 패널 뒷면의 장착 높이, 워크 좌표와 붓 고정 상태를 일관되게 반영해야 한다. G54나 툴 길이 보정을 중복 적용하지 않는다.

한지의 패널별·국소 편차 약 1–2 mm는 사용자 추정치다. 측정맵으로 위조하거나 모든 위치에 일괄 +2 mm를 적용하지 않는다. 실제 보정값이 없는 부분은 명목 표면을 쓴 검토 상태로 표시한다. 붓 탄성으로 잔편차를 흡수한다는 가정을 실제 일정 눌림의 검증으로 표현하지 않는다.

새 표면 기준이 없으면 현재 자료로 가능한 높이 범위·호버 가능성·경로 설계를 먼저 완성하고, 실행 수치 확정에 필요한 최소한의 추가 측정값을 구체적으로 알려줘. 이미 정리된 장비·스테이션·펌웨어 질문을 반복하지 않는다.

## 9. 고정 호버 후보와 Z=35 상한

이전의 모든 이동에서 표면+10을 추종하자는 지침은 **이번 1차 벤치마크에서는 고정 호버 평면을 우선 검토하는 방향으로 갱신한다.** 각 점의 접촉 높이는 계속 입체 표면을 따른다.

- 작품 내 고정 호버 후보: G54 Z=30 또는 Z=35.
- 기계 상한: 현재 설정과 사용자의 설명 기준 Z=35. 실제 machine/G54 변환도 확인.
- 초기 검토 목표: 이동 경로의 실제 최고 표면보다 10 mm 위.
- 물감통·세척·스펀지·주차는 기존 장비 좌표와 검토된 이송 규칙을 사용.

판정은 최고점의 **실제 첫 접촉 기계 Z**를 기준으로 한다. 최고 접촉 Z=20이라면 호버30에10mm 여유, 최고 접촉25라면 호버35에10mm 여유, 최고 접촉30이라면 호버35에도5mm만 남는다. 설계 높이20+호버10=기계Z30이라고 단정하지 않는다.

점의 최대 Z만으로 이동 여유를 증명하지 않는다. 전체 이동 구간과 고정물, 붓/홀더의 영역까지 확인한다. 고정 호버로 충분한 여유를 확보하면 비접촉 이동에서 매번 곡면을 추종할 필요는 없다.

필요한 여유가 Z=35 상한 안에서 나오지 않으면 원인과 수치를 보고한다. Z 상한을 올리거나 원점만 바꾸어 물리 여유가 생긴 것으로 처리하거나, 필요한 여유를 조용히 축소하지 않는다. 붓을 위로 잡는 등 장착 변경을 검토하는 경우에는 기존 물감통·세척·퍼지 접촉 Z에도 영향이 있음을 반영한다.

기존 `paper_contact_z_range=[-2,10]` 같은 평면용 제한도 그대로 입체 접촉 범위로 취급하지 않는다. 새 위치별 첫 접촉과 눌림을 반영한 한지 프로필의 범위를 검토하고, 원래 Spring 프로필을 전역 수정하지 않는다. 색 공급 동작에 한지 표면 오프셋을 더하지 않는다.

## 10. 점 단위 리필 상태 관리

기본값은 `refill_every_contacts=20`이다. 실제 작품에 찍은 접촉을 센다. 점을 한 번 눌렀다 떼면 1회이며, 공중 이동·스테이션 접촉·AIR 시뮬레이션은 소비한 작품 점으로 세지 않는다.

- 첫 색을 공급한 뒤 카운터0에서 시작.
- 20번째 접촉을 완료하고 이탈한 뒤, **21번째 작품 점 이전**에 같은 색을 보충.
- 같은 색 보충은 세척 없이 기존 공급 동작을 사용하고 카운터 초기화.
- 색이 바뀌면 기존 세척·퍼지·새 색 공급 후 초기화.
- 색 묶음 또는 작업이 20번째 점에서 끝나면 다음 점이 없으므로 불필요한 보충을 넣지 않음.
- 색 교체와 20점 한계가 동시에 오면 이전 색 보충을 생략하고 새 색으로 교체.
- 작업 도중 이어찍기에서는 마지막으로 완료한 점 ID를 기준으로 중복 없이 재개할 수 있게 계획 정보를 남김. 중단 뒤 현재 붓 상태를 알고 있다고 가정한 자동 재개는 하지 않음.

순수 점묘에서 기존 700 mm 색 거리 리필만 사용하면 거리 누적이 거의0이 되어 작동하지 않는다. 가짜 이동 거리를 누적해 대신하지 않는다. 한지용 카운터를 추가하고 실제 리필 이벤트와 읽기 검증에도 반영한다. 기존 거리 기준은 Spring용으로 보존한다.

보충 단위 설정은 한지 전용 프로필의 `refill_policy=contact_count`, `refill_every_contacts=20`처럼 명확히 분리한다. 1초 체류가20점보다 빨리 물감을 소모할 수 있다는 우려는 벤치마크로 판단한다. 실제 결과 없이 자동20→30 변경이나 가상의 잉크잔량 추정을 넣지 않는다.

**거리 누적 외의 붓 상태 처리도 확인한다.** 기존 `distance>0` 조건을 사용한 부분 소모/귀환/젖은 붓 이송 판단은 점에서 거리가0이어도 붓이 작품을 접촉했다는 사실을 놓칠 수 있다. 한지에서는 접촉 횟수 또는 명시적인 접촉 상태로 보충 후·사용 후 상태와 귀환 이송을 유지한다. 거리0이라는 이유로 사용한 붓을 마른 붓처럼 분류하지 않는다. 실제 물감 잔량이 측정되었다는 뜻의 상태명으로 표현하지 않는다.

정상 완주 시 예상값(원본 C, 색별 한 번 방문, 시작 공급 포함):

| 범위 | 점 수 | 사용 색 | 20점 기준 공급 총횟수 | 그중 같은 색 보충 | 색 교체 |
|---|---:|---:|---:|---:|---:|
| 전체 | 6,200 | 8 | 313 | 305 | 7 |
| 실물4번 | 890 | 6 | 47 | 41 | 5 |

공급 총횟수는 `sum(ceil(색별 점 수 / 제한))`로 계산한다. 전체 점 수만 나누면 색별 끝 묶음을 놓칠 수 있다. 점마다 물감량이 동일하다는 실측을 뜻하지 않으며, 20점 내 농도 유지 결과는 실제 시험에서 확인한다.

## 11. 벤치마크와 전체/개별 작업 출력

구현과 오프라인 검토의 우선순위는 다음과 같다.

1. **4번 전체 AIR:** 890점의 방문 순서와 보충·색 교체에 해당하는 비접촉 스테이션 경로를 검토한다. 실제 눌림·담금 없이 검토된 여유 높이에서 이동한다. 예정된20점 스케줄을 계산하는 계획 카운터와 실제 물감 소비 접촉 카운터를 구분한다. AIR가 실제 작품 접촉을 완료한 것으로 기록되지 않게 한다.
2. **4번 C4 40점 시험:** 4번의 C4 253점 중 정해진 아래→위 순서의 첫40점. 기본3mm/1초/20점으로 실행한다. 최초 공급1회,21번째 점 전 동일색 보충1회,40번째 뒤 추가 공급 없음. 이 시험은 보충 경계 전후를 확인하기 위한 부분 시험이다. 전체 작업의 첫 색 순서를 바꾸는 것이 아니다.
3. **4번 전체 벤치마크:** 원본890점, 6색, 색별 하단→상단,3mm/1초/20점. 첫 소규모 시험 결과와 별개로 전체 계획을 준비한다.
4. **본 작업 파일:** 전체600×600 조립 상태1개와 개별200×200 패널9개, 총10개 독립 작업을 준비한다. 개별 작업은 각각 로컬 좌하단(0,0) 기준이다. 4번 벤치마크는 그9개 중4번과 같으면 같은 파일을 참조한다. 사용자 작업공간 약800×900 내 실제 기계 좌표·스테이션 간섭을 검토한다.

40점 미리보기에는 **점1…40의 순번과 보충 전/후 경계20→21**를 표시하고, 접촉 횟수 배치와 높이를 기록한다. 실제 시험에서는 예를 들어1–5,16–20,21–25,36–40점의 농도·번짐·점 크기를 비교할 수 있게 별도 기록표를 만든다. 서로 위치·지형이 다른 점들의 차이를 잉크 고갈만으로 단정하지 않는다. 1초 정지 때문에20점 전에 눈에 띄게 흐려지면 이후 사용자가 보충 간격을 줄여 재생성할 수 있게 한다. 자동 분광/카메라 판정까지 구현할 필요는 없다.

기존 렌더링2.8mm는 실측 목표가 아니다. 대형 붓의 점이 더 크거나 겹칠 가능성을 미리보기에서 설명하되, 원본 점을 줄이거나 옮겨 해결하지 않는다.

**40점 시험과 전체890점은 좌표가 겹친다.** 두 파일을 같은 실제 패널에서 그대로 연속 실행하면40점을 두 번 찍는다. 시험을 별도 부재에서 할지, 실제 작품에 완료한 점으로 채택할지 구분한다. 동일 좌표·동일 조건으로 실제 완료했다고 확인된40점의 ID 목록이 있으면 이를 제외한850점 이어찍기를 만들 수 있게 한다. 실행되지 않은 시험을 완료 처리하거나 다른 조건의 시험을 동일 결과로 간주하지 않는다. 전체 파일과 개별 파일도 서로 대체 작업이므로 자동 연속 실행하지 않는다.

수치가 확정된 범위에서 실제 명령이 포함된 오프라인 검토용 G-code를 생성하고, 기존 정식 내보내기 규칙 및 물리 검토 상태를 보존한다. 새로운 기계 좌표를 확인하지 않은 채 실행 검증 완료로 표시하지 않는다. 미확정 물리값 때문에 실행용 수치 확정이 막혀도 점 계획·카운터·변환 코드·미리보기·시간 분석·단위 검증은 먼저 완성한다. 정확히 부족한 등록값만 보고하고 이미 정리된 하드웨어 질문을 되풀이하지 않는다.

각 완전한 작업에는 독립적인 시작 조건과 종료 처리가 있어야 한다. 기존 `FROM_PARK` 종료 세척 파일을 임의 시작 위치에서 실행할 완전한 프로그램처럼 사용하지 않는다. 장비 연결·전송·실행은 이번 Work 범위에 포함하지 않는다.

## 12. 기존 공급·세척·종료 처리

물감통·물·스펀지 좌표와 담그기·회수·물기 조절·립 동작은 PR32 기준 구현을 사용한다. 종이 위 접근 속도와 스테이션 접촉 속도는 구분한다. 실제 장착 기준이 바뀌지 않았다면 이미 정리된 물감통 접촉 조건을 새로 추정하지 않는다.

기본 작업의 루틴 M0를 추가하거나 매 리필마다 수동 확인을 요구하지 않는다. 의도적인 교정 작업에 멈춤이 필요하면 별도 파일로 명시한다.

완료 뒤에는 PR32에서 추가한 깊은 종료 세척을 한 번 실행한다.

- 물3회 방문, 각10초 담금 정지와3회 교반 및 기존 회수/얕은 닦기/립.
- 스펀지2회 접촉, 각4초.
- 마지막에 다시 물감이나 물을 묻히는 준비 동작 없이 회수·주차·M2.

현재 프로필의 `material.end_cleanup=false`만 보고 종료 세척을 생략하지 말아줘. PR32는 기존 완전한 작업 뒤에 종료 세척을 붙이는 별도 구현을 사용하므로 실제 생성 코드를 읽고, 한지 작업 끝에 중복 없이 한 번 적용한다. 기존 시작·주차·G54 설정 규칙도 읽고 따른다. 임의로 홈·G92·설정 쓰기를 추가하지 않는다.

## 13. 시간 분석과 미리보기

기존 시간 모델을 재사용해 이동 거리·속도·축 가감속·정지와 공급 동작을 반영한다. JD·가속도·스트리밍 등의 가정은 명시하고 계산을 실측으로 표현하지 않는다. 다음 항목으로 나눠 보여줘.

- 비접촉 XY 이동.
- 비접촉 Z 접근 및 호버 복귀.
- 접촉·추가3mm 눌림·제어된 이탈.
- 목표 깊이에서1초 정지.
- 스테이션 왕복 이동과 같은색 재보충 동작.
- 색 교체의 세척·퍼지·새 색 공급.
- 마지막 종료 세척·주차.

**정지 시간만의 합계:** 40점40초, 실물4번890초(14분50초), 전체6200초(1시간43분20초). 이것은 총 작업 시간이 아니다. 과거3mm/0.5초 계획과 이동/보충 조건이 같다면 정지시간 증가분만4번445초, 전체3100초다. 전체 예상 시간에는313회 공급과7번 색 교체 등의 비용이 추가된다.

30점이나4mm 비교 파일을 추가하는 것보다 기본3mm/1초/20점의 정확한 시간과 스케줄을 우선 완성한다. 20점 보충이 너무 잦거나 늦은지는 실측 후 설정 변경으로 판단한다.

필수 미리보기와 보고:

- 4번/전체 XY: 원본 점·색 배치, 실물 번호, 색별 시작점과 하단→상단 방향.
- 첫40점: 점 순번과20→21 보충 경계, 이후 재개할 점.
- XZ/YZ 또는3D: 명목/보정 표면, 최초 접촉 Z, 눌림 Z, 고정 호버 평면, 스테이션 이동.
- 시간표: 색 교체·동일색 보충·접촉·정지·이동의 구분.
- 파일별 원본 점 ID→실행 순번, 색, 글로벌/로컬/기계 XY, 설계/최초접촉/눌림 Z, 배치 내 접촉 번호, 보충 이벤트의 대응표.
- 실측 점 크기가 없는 부분은 가정한 미리보기 지름을 표시한다. 기존 색 값/팔레트 알파벳을 유지하고 실물 번짐을 정밀 재현했다고 주장하지 않는다.

## 14. 확인할 동작과 데이터 무결성

의미 있는 검증으로 다음을 확인해줘.

- 원본 C 전체6200점,4번890점과 색별 개수가 보존됨.
- 원본 좌표·색·패널 ID가 실행 순서 재배치 후에도 일치함.
- 위치별 최초 접촉 Z에서 정확히3mm 추가 눌림이 계산됨. Z 보정을 이중 적용하지 않음.
- 깊이 도달 뒤1.00초 정지가 읽기 검증에서도 유지됨. 이동 중 정지 시간이 소진되지 않음.
- 20점 후21번째 전 보충, 마지막 점 뒤 불필요한 공급 없음, 색 변경과 중복 공급 없음.
- 같은 색 보충에는 세척 없음, 다른 색 교체에는 세척 있음.
- 한지의 사용 색을 모두 한 번씩 방문하고 B1·B2·C5를 누락하지 않음.
- 고정 호버/스테이션 이동/눌림이 축 범위와 검토된 여유 안에 있음.
- 부분 시험·전체 작업·이어찍기의 점 중복 관계가 명시됨.
- 종료 세척이 한 번 들어가며 마지막 상태가 주차/M2임.
- 카운터 경계0/1/19/20/21/40/41 및 색 마지막 점이20의 배수인 경우를 확인함.
- 모든 좌표/깊이/시간/카운트 입력은 유한수·유효 범위를 검증함. NaN·누락값을0으로 조용히 대체하지 않음.
- 비접촉 AIR의 계획 카운트와 실제 접촉/실행 완료 기록이 구분됨.
- 사용한 붓 상태가 거리0 점묘에서도 유지되며 기존 젖은 붓 귀환 정책을 누락하지 않음.
- 기존 Spring 프로필/순서/파일이 영향을 받지 않음.

# 한지 부조 — 셀과 점의 밀도 스터디 v01

2026-10-22. 기존에 출력한 600 × 600 mm 부조를 유지하고, 직교·대각선 살과 한지의 결을 이용하는 점묘 채색을 비교했다. 자쿠추의 칸별 구성 원리를 참고한 현대적인 재해석이다. 원작의 문양이나 이미지를 복제하지 않았다.

먼저 **HANJI_PATTERN_STUDY_KO.html**을 열면 컬러/먹 농담, A–D 배치, 전체/실물 4번/바다/결 확대를 전환할 수 있다. 휠로 확대하고 드래그로 이동할 수 있다. 인터넷 연결 없이 실행된다. 같은 자료를 PNG로도 제공한다.

## 시각적 제안

우선 C를 검토하는 것을 제안한다. 기존안과 비슷한 점 수로도 점들의 묶임과 대각 흐름이 더 잘 보인다. B는 한지와 부조를 많이 남기지만 큰 덩어리가 약해질 수 있다. D는 면을 강하게 만들지만 밝은 점이 넓게 깔리며 셀별 차이가 줄어든다. 이는 화면을 본 제작상의 판단이며 사용자의 최종 선택을 대신하지 않는다.

| 안 | 전체 점 수 | 실물 4번 점 수 | 같은 지름 기준 가정 점 면적/전체 면적 |
|---|---:|---:|---:|
| A 기존 배열 | 5,826 | 849 | 9.96% |
| B 성긴 셀 리듬 | 3,600 | 449 | 6.16% |
| C 연결되는 셀 리듬 | 6,200 | 890 | 10.60% |
| D 조밀한 셀 리듬 | 8,800 | 1,423 | 15.05% |

점 면적 비율은 2.8 mm 원을 가정한 기하학적 값으로, 종이에서의 번짐·물감 소비량·출력 시간 예측이 아니다. 600 × 600 mm 전체에는 대부분 비워둔 하늘도 포함된다.

## 비교에서 고정한 것

- 기존 v0.10.1의 높이 함수와 3 × 3 패널 구성, 산·바다·해·달의 위치.
- 200 × 200 mm 패널, 직교 격자 실간격 9.9 mm, 칸마다 번갈아 바뀌는 대각선 방향.
- 8색의 원래 코드와 HEX. 렌더링의 점 중심색은 해당 HEX를 사용한다.
- 해·달 점군은 기존 좌표를 그대로 유지하여 각각 261점. 이번 스터디에서는 원형 자체의 패턴을 다시 만들지 않았다.
- 모든 비교의 가정 점 지름은 2.8 mm. A의 원래 인계 자료에는 2.2 mm로 기록되어 있으나, 여기서는 지름 차이가 밀도 비교를 방해하지 않도록 같은 크기로 표시했다.

## 실제로 바꾼 것

A는 원본 점 배열과 색 배정이다. B·C·D는 같은 새 후보/우선순위에서 점을 선택한다. B의 점은 C에, C의 점은 D에 모두 들어 있으므로 밀도 변화에 따라 더해지는 위치를 비교할 수 있다. A와 새 안들의 포함 관계는 보장하지 않는다.

직교 교차점과 살의 중간점에 더해, 실제 대각선 살의 1/4·1/2·3/4 위치를 사용했다. 대각선의 최단 새 간격은 약 3.50018 mm이다. 점의 중심은 모두 실제 살 위에 있지만 표시 원 전체가 살 폭 안에 놓인다는 뜻은 아니다. 주변 한지까지 붓이 접촉하므로 실제 지지 강성은 시험 대상이다.

네 가지 공통 모티프를 사용한다: 가로 연결, 세로 연결, 실제 대각 방향 연결, 모서리 강조. 산과 물은 서로 다른 그리기 기법을 쓰지 않고, 같은 모티프의 사용 비율과 색을 바꾼다. 산은 등고선·산맥의 장, 물은 잔물결의 장에 따라 연결과 여백을 만든다. 단순히 모든 점을 무작위로 늘리거나 사각형 윤곽을 그리지 않았다.

새 밀도안은 칸별 기본색/강조색도 다시 배정했으므로, A와 C의 차이는 점 개수만의 차이가 아니다. B·C·D 사이에서는 같은 위치의 색과 농담이 유지된다. 공유 교차점은 한 번만 남긴다.

## 먹 농담 안

컬러와 같은 좌표에서 I1·I2·I3 세 화면 농담을 배정했다. 단순한 컬러 이미지 회색 변환이 아니라 옅은 점/기본점/강조점의 역할로 배정한 비교안이다. 달의 가장자리에 약간 더 짙은 점을 두고, 해는 중묵·농묵으로 구분했다.

화면의 I1=#B3B4AB, I2=#74796F, I3=#2B352D는 한지 위에서 보일 농담의 예시이며 실제 먹의 색이나 희석비를 측정한 값이 아니다. 기존 A3 등 8색의 코드와 혼동하지 않는다. 한지 밝은 바탕은 물이나 흰 물감을 찍으라는 명령이 아니다.

## 화면과 실물의 관계

배경은 원래 높이 함수로 계산한 명목 표면의 음영이다. 조명 조건은 모든 안에 같고 높이 배율은 1이다. 옅은 직교·대각선은 종이에 드러날 결의 예시이며 실제 섬유·종이 처짐 측정 결과가 아니다. 이 선들은 채색 경로에 포함되지 않는다. 실제 출력 골조를 다시 생성하지 않았다.

가정한 얇은 점 가장자리도 물감의 확산 시뮬레이션이 아니다. 사용자가 말한 약 1–2 mm 표면 차이는 적용하지 않았다. 실제 건조 한지 보정, 붓 눌림·접촉시간·물감량은 후속 플로터 작업에서 확인한다.

뷰어의 지름 슬라이더는 2.2–3.4 mm 화면 비교용이다. 위치와 점 수는 바뀌지 않고 CSV도 수정되지 않는다. 새 안의 최단 중심 거리 약 3.50 mm에서 지름 3.4 mm는 약 0.10 mm 여백만 남기므로, 실물 번짐에 따라 합쳐질 수 있다.

## 좌표와 파일

`data/A_dots.csv` … `D_dots.csv`에 새 스터디의 좌표와 색·농담·지지 종류를 기록했다. **최종 채색 파일이나 G-code가 아니다.** 원본 데이터는 변경하지 않았다.

- `physical_panel_id`: 사용자 실물 번호. 위 1·2·3 / 중간 4·5·6 / 아래 7·8·9.
- `source_panel_id`: 원래 코드의 P01(좌하단) … P09(우상단) ID.
- `global_x_mm, global_y_mm`: 전체 좌하단을 원점으로 하는 글로벌 XY.
- `local_x_mm, local_y_mm`: 해당 200 mm 패널의 로컬 XY.
- `z_design_mm`: 원본 높이 함수의 명목 Z. 출력 뒷면이 0이며 패널별 최저점을 빼지 않는다.
- `study_dot_id`: 이 안에서만 유효한 새 ID. 기존 5,826점의 ID와 혼용하지 않는다.
- `source_dot_id_if_archived`: 원본 점을 그대로 사용한 경우의 원본 ID. 새 점은 비어 있다.
- `color_id`와 `ink_level_id`: 컬러안/먹안 중 하나를 선택해 사용한다. 한 점에 두 재료를 연속으로 찍으라는 의미가 아니다.

새 CSV는 대각선의 중간점 외 1/4·3/4 지점도 포함한다. `support_kind=diagonal_strut_point`에 해당하며 모든 위치는 실제 대각선 중심선에 있다. 색 선택과 실행 순서는 별개다.

## 재현 및 확인

Python 3, numpy, scipy, Pillow가 필요하다.

```bash
python study.py

```

`source/hanji_panel_v101_gh.py`는 원본 높이·골조 생성 코드의 변경 없는 복사본이다. `study.py`는 무거운 출력 메시 생성이나 STL 내보내기를 호출하지 않는다. 재현하면 데이터·이미지·검증 JSON이 생성된다.

`study_checks.json`에서 점 중심 중복, 실제 살 중심선과의 거리, 원래 높이 함수와의 일치, 지름 2.8 mm보다 큰 최근접 거리, B⊂C⊂D 관계를 확인했다. 실제 Rhino·슬라이서·플로터 실행은 이번 시각 스터디의 범위에 포함하지 않았다.

현재 GitHub 백엔드 준비 완료를 기다리는 방침은 유지한다. 이 스터디는 선택 전의 채색 후보이며 기존 인계 자료·원본 코드·저장소를 수정하지 않는다.

1. A three-region response is not three knots

Use the unchanged multi-knot BrushCalibration piecewise-linear mapper. The principal regions are .20–.40, .40–.60 and .60–.93. The lower 0–.20 calibration interval and upper .93–1.0 reserve are separate. Six knots are the minimal arrangement with these four boundaries and both global anchors.

After the common 3-mm compression at .20, the preferred .40/.60/.93 knots use 8% / 24% / 85% of the remaining compression budget. These are transparent design hypotheses, not fitted physical measurements. The principal compression slopes are 2.8 / 5.6 / 12.94 mm per intent unit for A and 3.6 / 7.2 / 16.64 for B. The .93–1.0 tails remain monotonic at 15.0 / 19.29 mm per intent unit. The original maximum .93 maps to 8.95 / 10.65 mm, leaving 1.05 / 1.35 mm to the global endpoint.

Fair comparisons: global linear C(p)=Mp gives .20→2.0 / 2.4 mm and therefore does not satisfy the requested 3-mm anchor. Anchor-preserving linear uses 0→0, .20→3, 1→M. The convex reference samples C=3+(M−3)((p−.2)/.8)² above .2 into eleven piecewise-linear knots; it is a quadratic-shaped reference, not an exponential fit or spline. Maximum quadratic interpolation error is at most about 0.027 / 0.035 mm here, unrelated to physical accuracy.

Both outer domains are explicit, with no extrapolation outside 0–1, reversal or overshoot. Work Z is minus compression. Values apply at original accepted vertices; each original G1 segment interpolates its endpoint XYZ. No new vertices are inserted when an artistic-pressure segment crosses a calibration knot. Slope continuity is not claimed; physical microsegment tests determine whether any later interpolation improvement is needed.

The region model gives independent low/middle/strong control. It keeps ordinary A behavior relatively shallow while preserving a steeper high-intent response. It has no proven artistic advantage until physical marks are compared. Global-linear A is slightly faster for D color; the anchor-preserving linear control is slower than the preferred curve. This separates response design from a blanket speed claim.

Low acceleration gives D color 15.307 / 15.402 h, so the 4–5-hour target is conditional on measured, brush-compatible dynamics. The DEV reference has XYZ rates 15,000/15,000/8,000 mm/min and accelerations 1,200/1,200/1,000 mm/s²; the low case uses 15,000/15,000/6,000 and 100/100/20. Both assume synthetic junction deviation .01 mm, absent from the DEV YAML. The DEV file is unverified and exceeds current fixture brush-acceleration limits; using it in a study never authorizes motion.

Neither model is a verified printing time or bound. Full lookahead and continuous streaming are assumed; finite buffer, step rounding, serial/CPU overhead, mounting variation, actual brush compression/recovery and operator preparation/drying are not modeled. The roughly 27-minute margin from A’s DEV result to five hours is not a hardware guarantee. Stop-each-segment sensitivity values are retained in the JSON.

Use the fixed 18-pattern coupon inside a nominal 140×260-mm area (actual reachable/free paper area must be measured), preserving the same geometry between A/B and media. Constant, 5-mm, 100-mm and continuous rise/fall patterns exercise entry bloom, ordinary marks, strong D/rock marks, sustained loading and recovery. Pressure transitions are test strokes, separate from the accepted artwork.

Record wet/dry width at start/middle/end, continuity, pigment distribution, paper disturbance and recovery time/clearance, plus photos with scale. Record the brush’s actual free length/mount, medium/dilution/glue/reference loading, substrate/mounting, exact depth/feed and installed acceleration/junction settings. Stop or reduce if clearance is uncertain, paper fibers lift, marks split/pool, or recovery is incomplete. No width or safety result is prefilled.

Before physical execution: confirm installed controller/frame/limits/E-stop; establish and verify G54 first-contact Z0; measure the free approach/hover/recovery envelope, station contacts and park; obtain current air/contact/calibration evidence and separate operator authorization. Coupon tests may intentionally stop for observation; production retains zero routine M0. No executable benchmark or production Spring file is created here.

Optional p=1.0 tests establish the actual 10/12-mm endpoints only after smaller depths pass. To enable a full 0–1 measured mapping, existing gates require observations at every retained knot, including 1.0. If that endpoint is not cleared, keep this candidate unverified or separately review a measured domain ending at .93 with its same 8.95/10.65-mm depth; do not silently move .93 to the maximum or extrapolate.

first_depth.request.json is a non-executable request in the existing v0.3 constant-Z calibration schema for only the first −0.25-mm, 20-mm line. Its coordinates, depth and speed still require physical approval. Later depths are separate reviewed requests. The full benchmark_plan.json is a design, not direct CLI input: the existing calibration CLI supports isolated constant-Z lines; continuous-pressure coupons require the existing test-source planning/export API with measured profiles, current evidence and separate authorization after the initial depth tests. This study generates neither program.

Eight focused study tests plus the unchanged backend regressions cover monotonicity, anchors, editable configuration, source preservation, Z caps, synthetic-only export rejection and benchmark design.

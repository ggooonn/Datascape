# Configs

- `palettes/palette_20.yaml`: user-supplied display colors, not measured dry pigment colors.
- `substrates/four_seasons.yaml`: candidate materials and provisional preview colors.
- `rendering/seoul_four_seasons.yaml`: agreed panel layout; viewpoints and random seed remain unset.

Preview opacity and line width are separate from pigment concentration and brush pressure. Tool coordinates, machine Z values, and calibration records belong in `hardware/fluidnc/`.
